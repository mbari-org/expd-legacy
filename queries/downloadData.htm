Download ROV CTD Data

The ROVs Ventana and Tiburon have sensors that measure the conductivity, temperature, pressure, dissolved oxygen, and light transmission of seawater during each dive. These ROV CTD data are processed daily and archived in the MBARI Expedition Database.
1.  Choose the date
 Year      Day of year ddd    OR
 Dive   OR
 Start mm/dd/yyyy / /   hh:mm:ss ::
      End mm/dd/yyyy  / /    hh:mm:ss ::

Time is in UTC. Leave the default times to return data by entire UTC days.

2.  Choose the vehicle
  Ventana               Tiburon
3.  Choose the format of the results
 Comma delimited   HTML Table   Microsoft Excel

Warning: large queries may fill your computer's memory cache and crash the browser (especially if you choose the HTML Table format). Break your query into shorter time periods, or see use other query methods.
