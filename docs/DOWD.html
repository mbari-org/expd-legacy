NAME

DOWD.pm - Directory Of Web Data: Provide info on Expedition data that live on the web

SYNOPSIS

    use DOWD;

DESCRIPTION

This module was written to support the popExpeditionData.pl script which is used to (of course) populate the ExpeditionData table inside the Expd database. It has some perhaps useful methods to discover files that live at web addresses. It make significatnt use of the LWP::Simple module to do this.

Methods

init()

Example: 

        $dod = new DOWD;
        
        $dod->init;
        
        Initialize internal variables that help this package know about the data.  The primary
        data member is $dod->{RootWeb}.

nextDir()

Example: 

        $dod = new DOWD;
        
        for ($year = 1999; $year <= 1999; $year++) {
        
                foreach $DataType ( ('frameGrabs', 'rovctd') ) {
         
                        $dod->nextDir( ParentDir => $DataType, Platform => 'vnta', Year => $year);
        
        The nextDir() method will setup the necessary internal lists based on the
        passed parameters.  The method constructs a list of files from which nextFile()
        reads.

nextFile()

Example: 

        $dod = new DOWD;
        
        while ( $dod->nextFile ) {
        
                        $URL  = $dod->{url};
                        
                        $LinkText  = $dod->{linktext};
                        
                        $s_dtg  = $dod->{startDtg};
                        
                        $e_dtg  = $dod->{endDtg};
                        
                        $UnixPath  = $dod->{unixpath};
                        
                        $WindowsPath  = $dod->{windowspath};
                
        Returns 0 when at the end of the list.

_getDirs()

Internal method to get the contents of a web directory. It parses the html received by a LWP::Simple get() call on a URL.

_getFiles()

Internal method to get the contents of a web directory. It parses the html received by a LWP::Simple get() call on a URL. An optional second argument can be passed to return only files that end in the specified string ($ext).

_frameGrabInfo()

Internal method to return the information (link text, start & end times, and physical paths) about a set of frame grabs that are pointed to by a thumbnail index page. Typically called by nextDir() for constructing the list of these items. This method encapsulates the knowledge of where and how to look for start & end info and unix/Windows path names.

Unfortunately, unix and windows paths will often change requiring edits of this function. I don't know how important it will be to keep track of this info as we plan to keep the http://mww.mbari.org/ARCHIVE the ``official'' location of these data no matter where they physically reside.

Returns a list. Example:

($text, $start, $end, $unix) = @{$self->_frameGrabInfo($_dirstring, $file)};

_rovctdInfo()

Internal method to return the information (link text, start & end times, and physical paths) about a set of web accessible files that relate to ROV CTD data. Typically called by nextDir() for constructing the list of these items. This method encapsulates the knowledge of where and how to look for start & end info and unix/Windows path names.

Unfortunately, unix and windows paths will often change requiring edits of this function. I don't know how important it will be to keep track of this info as we plan to keep the http://mww.mbari.org/ARCHIVE the ``official'' location of these data no matter where they physically reside.

Returns a list of list references. Example:

(\@urlList, \@textList, \@startList, \@endList, \@unixList, \@windowsList) = @{$self->_rovctdInfo($_dirstring, $dir)};
