NAME

popExpeditionData.pl - Populate ExpeditionData table

SYNOPSIS

    > popExpeditionData.pl <startYYYY[DDD]> [endYYYYDDD] | <last(ndays)>

DESCRIPTION

This script examines all of the files that reside in the Web tree starting at http://mww.mbari.org/ARCHIVE, determines the start and end time for the file, checks the Expedition and Dive tables to capture Expedition and Dive foreign keys for placement as a record in the ExpeditionData table. If there is no foreign key match then no record is added.

If no arguments are specified then the last 7 days or so of data directories are examined and linked in.

The process is basically as follows:

1. Loop through the years

2. Loop through the data types

3. Loop though all possible Parent directories for the data type (e.g. Camera Log is in both logger and camlog)

4. Loop through each possible platform dir for each parent dir.

5. For each ``file'' found look up the dive/expedition it belongs to. Assemble info into a record.

6. Loop through each of these records and insert them into the database using a stored procedure.
