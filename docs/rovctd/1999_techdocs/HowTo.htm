Standard Procedures for ROV CTD Data Maintainer

These are the procedures used to manually maintain the ROV CTD data at MBARI.

  • Manually Process pl/wflogger Files
    • Log into barnacle as rovctd
    • Type: setvnta or settibr as needed
    • Type: processCtd [startYYYYDDD [endYYYYDDD]]
  • Manually Load Data Into the Database
    • Log onto an NT machine which has active perl and SQL 7.0 ODBC installed
    • Get the loadRovctd.pl and loadRovctd.bat from Visual Source Safe   - Rovctd - load_unload on Fog (Ask IAG for help if needed)
    • In a DOS window type: CD loadRovctd_file_directory
    •     then type: loadRovctd vnta|tibr [fromYYYYDDD [toYYYYDDD]]
  • Manually Unload Data From the Database
    • Log onto an NT machine which has active perl and SQL 7.0 ODBC installed
    • Get the unloadRovctd.pl and unloadRovctd.bat from Visual Source Safe  - Rovctd - load_unload on Fog (Ask IAG for help if needed)
    • In a DOS window type: CD unloadRovctd_file_directory
    •     then type: unloadRovctd vnta|tibr [fromYYYYDDD [toYYYYDDD]]
  • Manually REprocess a Full Day
    • Manually unload the data from the database (see above directions)
    • Manually move the logger files back to the process directory and delete the files created from the original processing;
      • Log into barnacle as rovctd and type;
        • setvnta or settibr
        • cd $archive/YYYY/DDD
        • mv *rovctdlogr.dat.gz $process
        • cd ..
        • rm -Rf DDD
    • Manually process the pl/wflogger files (see above directions)
    • Manually load the data into the database (see above directions)
Note: All YYYY above refer to the 4 digit year and all DDD refer to 3 digit day-of-year.
