Program Name raw2Der.perl
Summary This processs take the YYYYDDDxxxxRovCtdRaw.txt and YYYYDDDxxxRovCtdCoef.txt files, bin averages the data to 15 seconds, despikes it using despikeCIN, processes it through recalcCtd, cleans it up and produces theYYYYDDDxxxxRovCtdDer.txt file.
Usage raw2Der.perl [fromYYJJJ [toYYJJJ]]
Options fromYYYYJJJ - Starting date number
toYYYYJJJ - Ending date number (assume one day if empty)
if left blank does last 30 days
Language perl
Author Holly Baum
Contact Dan Wilkin
Src Location $HOME/bin
Dependencies requires perl version 5.00 or higher
requires environment variables; HOME, rovName, process, archive, DEBUG
$HOME/bin/despikeCIN
$HOME/bin/recalcCtd
