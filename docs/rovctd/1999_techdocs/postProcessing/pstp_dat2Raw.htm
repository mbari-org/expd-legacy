Program Name dat2Raw.perl
Summary Processes the "raw" data from the ROV log file (YYYYJJJrovctdlogr.dat) into the YYYYDDDxxxxRovCtdRaw.txt and YYYYDDDxxxxRovCtdCoef.txt files
Usage raw2Dat.perl  [fromYYYYJJJ [toYYYYJJJ]]
Options fromYYYYJJJ - Starting date number
toYYYYJJJ - Ending date number (assume one day if empty)
if left blank does all logr files it can find in process
Language perl
Author Holly Baum
Contact Dan Wilkin
Src Location $HOME/bin
Dependencies requires perl version 5.00 or higher
requires environment variables; HOME, rovName, shipName, process, archive, webDir and DEBUG
