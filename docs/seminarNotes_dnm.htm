Documentation and other ways to the data

Where to go for more information?

  • Expd home page with information about the development effort, the data, contact information.
  • For info about the ROVCTD data, see the user documentation.

What other searches are available from the web?

  • Use the ROVCTD search page to query for specific time periods, vehicle data. Can return text, Excel, HTML. Don't use HTML for large datasets—it's SLOW!
  • Use the Expedition search pages to quickly see all related data. Note dive-specific queries for ROVCTD (if a post-cruise and dive times have been entered!) and links to processing steps.
  • Wondering what other information is on the web? See the Data Archives link.

How can I create my own queries?

It is now easier than ever to use standard applications (MS Excel, MS Access) to extract the information you need to analyze. We will demonstrate this in the follow-on advanced queries section of this seminar.
