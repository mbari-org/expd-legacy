About the MBARI Expedition and ROV CTD Data Management System documentation

This document describes the MBARI Expedition and ROV CTD Data Management System, which includes the Expedition Database and the software applications designed for loading data into it and extracting data from it. This document is written primarily for the system's developers, programmers, and other high level users for the purposes of reference and support of the system. Instructions for executing the processes and links to more information for end users are included. This document and the system are under development.

This data management system provides important functionality by:

  • Streamlining the steps needed by other programs to access the expedition and ROVCTD data. Many MBARI applications depend on these data: the expedition log entry program (precruise and postcruise reports), the expedition web pages, the ROVCTD web pages, and other databases (e.g., VIMS, Samples Database).
  • Allowing easier data access. In the past, scientists and other users have needed special UNIX emulation software on their PC or Macintosh to create their own queries with the Sybase Database Workbench tool. By using SQL Server, users can create queries with MBARI-wide desktop tools such as Access, Excel, Front Page, and Netscape.
