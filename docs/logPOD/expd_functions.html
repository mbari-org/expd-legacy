FUNCTIONS

open_database()

Create the database connection object. Receive the DSN. Does a little error checking. $Conn is global.

Author: Mike McCann

Date Created: 11/3/8

FixString()

Put quotes around text values and nothing around numbers escape embedded quotes.

Author: Mike McCann

Date Created: 10/28/98

toGMT()

Convert local time array to a GMT string that is good for a database DTG load.

Author: Mike McCann

Date Created: 10/28/98

toGMTfromES()

Convert local time array to a GMT string that is good for a database DTG load. Should have overloaded toGMT, but I feel this is safer.

Author: Mike McCann

Date Created: 7/19/99

toYDfromDate()

Compute Year and YearDay given a GMT m/d/y.

Author: Mike McCann

Date Created: 7/27/99

URLEncode()

Make variables safe for a URL.

Author: http://eclectic.kluge.net/codesnippets/perl/URLEncode.html

Date Created: 10/28/98

dataLinks()

Do DB query against ExpeditionData table and output href links a text. Assumes $Conn object already opened. This function is to be called within an area where the DB is opened.

Author: Mike McCann

Date Created: 9/15/99
