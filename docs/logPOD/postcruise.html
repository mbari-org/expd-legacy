SYNOPSIS

    http://expd.mbari.org/expd/log/postcruise.asp

DESCRIPTION

Postcruise processing Active Server Page. Search for existing precruise record and offer editing of fields that can be filled in during the postcruise process.

Mike McCann MBARI

November 1998

FUNCTIONS

step1()

Offer simple way to search for existing cruises in the database.

Author: Mike McCann

Date Created: 11/16/98

advanced_search()

Offer ways to search for existing cruises in the database.

Author: Mike McCann

Date Created: 11/16/98

step2()

Return list of cruises from query specified in step1() or advanced_search()

Author: Mike McCann

Date Created: 11/16/98

step3()

Present cruise info for editing.

Author: Mike McCann

Date Created: 11/18/98

display_expd()

Same as step3(), but don't present form fields. Save text in session variable for postcruise email message.

Author: Mike McCann

Date Created: 12/4/98

construct_option_lists()

Construct option lists for use in the DTG Month/day/year pull-down boxes.

Author: Mike McCann

Date Created: 11/19/98

SelectEpoch()

Select epoch seconds from database field specified.

Author: Mike McCann

Date Created: 10/28/98

process_form_entries()

Verify entries before submitting them, does the work of creating all the DB session variables. Session variables are not assigned unless it is meant to be there, i.e. the field requires updating because it was entered on the form and is different from what was in the database.

Author: Mike McCann

Date Created: 10/20/98

update_expedition()

Process the form field entries and insert into the database Here is where we need to map the names we have on the HTML forms for all the fields to the names of the fields that are actaully in the database table.

Author: Mike McCann

Date Created: 10/28/98

email()

Process the form field entries and mail to the Logistics coordinator.

Author: Mike McCann

Date Created: 11/5/98

finished_email()

Send message to the postcruise alias (or whatever was entered on the step3() form.

Author: Mike McCann

Date Created: 12/7/98
