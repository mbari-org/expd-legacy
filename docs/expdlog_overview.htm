Expedition Log system overview

The Expedition log programs are used to plan MBARI cruises and to log the reports from those expeditions.

The requirements for this system are as follows:

These is not an exhaustive list of requirements, but does list the salient features of the system.

  1. Design new Expd data base that
    · Preserves the data that have been entered into MODB over the last 10 years
    · Denormalizes the design to allow for easier loads & queries
    · Decouples data loads from other database entry events
      (Doesn't hold any data input hostage to other data being in the database.)
  2. Enter a "precruise" into the database
    · Only the logistics coordinator may enter a precruise into the database.
    · All other users can file a postcruise using the same web form; however, rather than the entries going into the database they will instead be mailed to the logistics coordinator who will review it and do the database entry.
    · Upon entry into the database a text mail message will be sent to the 'precruise@mbari.org' mail address.
  3. Enter a "postcruise" into the database
    · Only a "registered user" may enter (or edit) a postcruise in the database.
    · All other users can file a postcruise using the same web form; however, rather than the entries going into the database they will instead be mailed to the logistics coordinator who will review it and do the database entry.
    · Upon entry into the database a text mail message will be sent to the 'postcruise@mbari.org' mail address.
  4. Edit dive information (start & end times, etc.)
    · Allow for multiple dives to be assigned to an expedition.
    · View processing steps of ROVCTD data to help determine start and end times.
    · Edit dive times using either epoch seconds or local time (pilot's database uses local time).
  5. Search the database by
    · Date range
    · Any string that can appear in any of the text fields
    · Dive number
    · Ship sequence number (record number historically used by logistics coordinator)
    · Chief Scientist, or Principal Investigator
  6. Provide links to associated data, including
    · Video Frame Grabs
    · ROVCTDO data
    · Ship and ROV navigation data
    · Samples in the Samples database

Roles

There are 3 roles defined for users of the Expedition Log system

  1. Logistics coordinator: approves end enters precruises.
  2. Registered user: enters/edits postcruise reports.
  3. Everyone else on MBARI's Intranet: search database, enter precruises & postcruises from web forms, entered into database by Logistics Coordinator.\

Implementation

The system is implemented as a set of Active Server Pages running on an NT server with IIS4, ActiveState perl, and native connection to SQL 7.0 relational database.

Implementation with web forms insures that anyone with a web browser on MBARI's Intranet can submit precruises, file post cruises, and search the database. Furthermore, the web implementation (being stateless, it can tolerate network instability) offers the ability for postcruise entry from the ship immediately following operations.
