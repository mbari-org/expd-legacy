Expedition Data Links

Early each morning two scripts are run which populate the ExpeditionData table in the Expd database. They are popExpeditionData.pl and popEDwithDBqueries.pl. A batch job in \\godzilla\DTS\EXPD\Expedition named ExpeditionDataLoads.bat is run by SQL Server at 0200 each morning. Parameters for how far back in time these scripts look are placed in this batch file.

As of 28 February 2003 we look back 40 days for new file links and 365 days for database query links. If Samples, Annotations, or rovctd database entries are made that precede this time window then popEDwithDBqueries.pl can be run by hand following the instructions below.

Running popEDwithDBqueries.pl by hand

  1. Install ActiveState perl version 5.22 on your computer. Download the installer from here and execute it on your system.
  2. Create a drive mapping from \\godzilla\SQL7DATA to a drive letter on your machine, e.g. G:
  3. Execute a query of the Expedition database for the expeditions that need database query links added. Note the beginning and ending ExpeditionID number for the range of expeditions that need the links added. These numbers are listed in the lower right hand corner of the Expedition Report cell in the data table return page, so you should check the data table format radio button on the query form.
  4. Once you have the start and end ExpedtionID numbers execute the following on your PC:

g:
cd \DTS\EXPD\Expedition
perl popEDwithDBqueries.pl 2420 2420 (for a single expedition)

or

perl popEDwithDBqueries.pl 1899 2095 (for all expeditions in year 2000)

Note that ExpeditionIDs are assigned sequentially during the precruise entry process. A range of ExpeditionID numbers may not encompass all of the expeditions within a certain time range.

 

Running popExpeditionData.pl by hand

  1. Install ActiveState perl version 5.22 on your computer. Download the installer from here and execute it on your system.
  2. Create a drive mapping from \\godzilla\SQL7DATA to a drive letter on your machine, e.g. G:
  3. For the range of time you need to update links for execute popExpeditionData.pl with the proper YYYYDDD arguments, e.g.:

g:
cd \DTS\EXPD\Expedition
perl popExpeditionData.pl 2000001 2000365 (for all expeditions in year 2000)
