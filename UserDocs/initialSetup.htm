Initial Setup of SQL Server and ODBC Drivers

To create advanced queries to the Expedition database, your computer needs software that can map the database server to your desktop. This software is built-in to the operating system and/or is available from the Microsoft Office package. You only need to complete the following installation and configuration steps one time on your computer. If you difficulties with the setup, contact the database administrator Mark Blackburn.

Microsoft SQL Server Driver Setup

A few necessary components are not installed automatically with the "typical" Microsoft Office installation. You will need to add the "Data Access" components by following the steps below:

1) Run \\Typhoon\Apps\Office.97\Setup.exe
2) Press the "Add/Remove" button
3) Select the "Data Access" option and press the "Change Options" button
4) Select the "Database Drivers" option and press the "Change Options" button
5) Check the "Microsoft SQL Server Driver" box and press the "OK" button
6) Check the "Microsoft Query" box and press the "OK" button
7) Press the "OK" button

ODBC Setup

Use the Control Panel to map an ODBC driver on your computer to the Expedition database.

Beginning at the the Windows Start Bar,
1) Select Settings->Control Panel->32-bit ODBC
2) Select the System DSN tab, then Add...
3) Select SQL-Server from the menu list.

4) In the ODBC SQL-Server setup page **These instructions are generic for Windows-based systems but there are some differences with WinNT):

Data Source Name is whatever name you want to give this mapping. For example, ExpeditionDB.

The Server is FOG (leave Network Address and Library as Default)

Select Options>>

The Database Name is expd

Check Use ANSI Quoted Identifiers, Use ANSI Nulls, Padding and Warnings, and Convert OEM to ANSI characters.

5) Press the "OK" button. You may want to restart your computer at this point to ensure that the changes will take effect.
