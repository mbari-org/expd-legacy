Ventana CTD System
The sensor suite on the ROV Ventana currently consists of a Falmouth Scientific micro-CTD, a Sea Tech 25 cm path transmissometer operating at 660 nanometers, and a pumped Sea-Bird model 13 oxygen sensor with a Beckman type membrane. Data are acquired at a nominal rate of 4 Hz, then averaged and archived in 15 second bins. Prior to 1996 CTD data were acquired with a Sea-Bird model 9 CTD system.

Tiburon CTD System
The sensor suite on the ROV Tiburon currently consists of modular Falmouth Scientific conductivity, temperature and pressure sensors, a Chelsea Alphatracka 25 cm path transmissometer operating at 660 nanometers, and a pumped Sea-Bird model 13 oxygen sensor with a Beckman type membrane. Data are acquired at a nominal rate of 10Hz, then averaged and archived in 15 second bins.

Getting to the Data

Standard Queries

Use the following web-based queries to download ROVCTD data for analysis. The data source is the Expedition database and the returned data include quality flags. Note that times are in UTC; subtract 7 or 8 hours for local time, depending on whether it is daylight savings time or not.

  • ROVCTD search page
  • Expedition search pages

Advanced Queries: Using Other Tools

If you have more number-crunching needs, you can write your own queries. Microsoft Office provides ODBC drivers that allow you to map the Expedition database to your desktop. Once you've enabled ODBC to the database, you can use analysis applications such as MS Excel and MS Access to create your own custom queries.

Initial Setup—Before you get started, you need to make sure that your computer has the following components by completing the initial setup steps (only need to do this once):

  • Install the Microsoft SQL Server driver and MS Query.
  • Create a 32-bit ODBC link to the Expedition SQL Server database.

Login name and password—The other important information that you will need is the username and password to use. Whenever you are prompted by the Expedition database, use:

username: everyone
password: guest

Know the fields—You will need to know the table and field names that you want to retrieve. The primary data tables are shown is this graphic.

Using MS Excel
  • Open a blank MS Excel spreadsheet and select Data->Get External Data.
  • Select Run a New Query.
  • In the data source list, select the name of the Expedition database.
  • The wizard will guide you through the process of creating your query. Refer to the Microsoft Help pages for troubleshooting and advanced options.
Using MS Access

Using Access to query a SQL Server database like Expedition is very similar to working with a locally-created database. All you need to do is to first link or load in the tables you want to query. Linking tables is recommended so that you always have the current data. Select File->Get External Data->Link Tables. Refer to Microsoft Help for more information.

Using MS Query

This tool can let you quickly develop a query and see the results. It is much faster than Access or Excel due to the execution engines of those two programs. Queries created with MS Query (.dqy files) can be run directly from MS Excel. You'll probably need to create your own shortcut to this program in your start bar. Look in the directory where MS Office has been installed to find the program.

Data processing files

As a separate archive, the ROVCTD files created during processing are saved on a server. You can access these from the Expedition search pages or directly from the ARCHIVE file tree. These files include the raw data files, "derived files" (with the processed data and calculated values), postscript and gif formatted plots, daily statistics, the coefficients, and log files. These data files do not contain quality flags (download ROVCTD data from the Expedition database for quality flags).
