Derived ROVCTD data file

The derived data file contains measured and derived values that have been averaged to 15-second bins and processed through a despiking filter. The files are named in the convention YYYYDDDvntaCtdDer.txt. The files are comma-delimited ASCII text files that can be easily imported in applications such as MS Excel and ArcView. The first line of the file provides a shortened name (a "header") for the data field.
