Raw ROVCTD data file

The raw data file contains measured values at 2-second intervals. The files are named in the convention YYYYDDDvntaCtdRaw.txt. The files are comma-delimited ASCII text files that can be easily imported in applications such as MS Excel and ArcView. The first line of the file provides a shortened name (a "header") for the data field.
