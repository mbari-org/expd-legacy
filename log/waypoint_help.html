MBARI Waypoint Management

Instructions

Use the MBARI Waypoint Management webpages (http://expd.mbari.org/expd/log/waypoint.asp) to add, edit, delete, export, and import your waypoints.  Changes you make through these web pages will directly affect the waypoints in MBARI's Expedition database.  Only modify or delete waypoints that you own.

To view a set of waypoints:

1. Choose a waypoint owner or "show all waypoints"

2. Click on the "View" button.

3. Click on a column header to sort by the values in a column.

4. Click on the same column header again to reverse the sorting order.

To edit an existing waypoint:

1. View a set of waypoints.

2. Click on the "Edit" link on the row of the waypoint you want to edit.

3. A form will appear in a new browser window.  Modify some of the values in the form.

4. Click on the "Update" button.

5. If any conflicts or errors occurred, correct them and resubmit the form.

6. If you decide not to change the waypoint, simply close the new browser window.

To delete a waypoint:

1. View a set of waypoints.

2. Click on the "Delete" link on the row of the waypoint you want to delete.

3. If you delete a waypoint unintentionally, click on the "Restore" link.

To add a waypoint:

1. Click on the "Add" link.

2. Fill out the required fields and any additional information you want to provide.

3. Click on the "Add" button.

4. If any conflicts or errors occurred, correct them and resubmit the form.

Note: If you want to work quickly with a large set of waypoints, export them to a text file, modify them in an external application, and import them into the database.  As you import waypoints from a file, new waypoints will be added, modified waypoints will be updated, and unchanged waypoints will be skipped.

To work with a set of waypoints in an external application such as Notepad, Excel, or Arcview:

1. View a set of waypoints.

2. Above the table, click on the "Export" link.

3. "Save As" the text file on your computer.

4. Import the file into Arcview or Excel, or open the file in Notepad or another text editor.

5. View/modify/add waypoints.  Note: you can delete waypoints from the external file, but they won't be deleted from the database as you import the file.  The only changes to the database that the import can make are additions and updates.

6. Export/Save the file as comma delimited text.

7. From main Waypoint Management webpage, choose the "Import" link.

8. Browse to your file. Click on "Submit Query".

9. View the results. You'll see a summary of added, updated, and skipped points (and a list of errors if there are any).

To prevent a waypoint from ever expiring, remove (set to blank) the expiration date.
